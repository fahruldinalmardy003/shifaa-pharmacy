# نظام إدارة صيدلية الشفاء

واجهة عربية ثابتة لإدارة الأدوية والتصنيفات والإعدادات.

## التشغيل

افتح `index.html` مباشرة أو شغّل خادمًا ثابتًا محليًا:

```bash
python3 -m http.server 8000
```

## ملاحظات مهمة

- هذا مشروع Front-End فقط؛ البيانات تُحفظ في `localStorage` داخل المتصفح ولا توجد قاعدة بيانات أو مزامنة بين الأجهزة.
- كلمة المرور الافتراضية الحالية هي `1234` ويمكن تغييرها من داخل الواجهة، لكنها ليست حماية أمنية حقيقية لأن التحقق يتم في JavaScript داخل المتصفح.
- لا يُنصح باستخدام هذه النسخة لتخزين بيانات مرضى أو معلومات صيدلية حساسة قبل إضافة خادم خلفي ومصادقة حقيقية.
